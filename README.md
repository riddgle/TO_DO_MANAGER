# 📝 To-Do Manager

Project Python đầu tiên của mình.

Đây là ứng dụng quản lý công việc đơn giản chạy trên Terminal (Command Line), được xây dựng nhằm luyện tập các kiến thức Python cơ bản.

## 🚀 Chức năng

- Thêm công việc
- Xem danh sách công việc
- Hoàn thành công việc cuối cùng
- Xóa toàn bộ danh sách
- Xóa công việc theo tên
- Kiểm tra lỗi khi người dùng nhập sai dữ liệu

## 📚 Kiến thức sử dụng

- Biến
- List
- Function (`def`)
- `return`
- `while`
- `for`
- `if / elif / else`
- `try / except`
- `append()`
- `remove()`
- `pop()`
- `clear()`
- `len()`
- `in`

## 💻 Cách chạy

```bash
python todo.py
```
